## ⚠️ الأهم: لم يُنشر شيء بعد
كل التحديثات الكبيرة أدناه **محفوظة بالكود بس ما اتنشرت على السيرفر**. المطلوب لما يرجع الـShell:
1. Push من GitHub Desktop.
2. تفعيل swap + إيقاف ollama وقت البناء (LibreOffice ثقيل).
3. Redeploy على Coolify، ثم إرجاع ollama.
4. اختبار توليد مستند PDF/Word للتأكد.

## ✅ أُنجز (بانتظار النشر)
- إصلاح تكرار محتوى المستندات + تعريب كامل RTL لكل الأنواع.
- تصميم Word: غلاف بهوية + شعار، رؤوس مرقّمة، جداول ملوّنة (RACI/مخاطر)، ترقيم صفحات، خط Noto عربي.
- **PDF عربي سليم** عبر DOCX→LibreOffice (بدل jsPDF)، مع طابور تزامن + `nixpacks.toml` يثبّت LibreOffice والخطوط.
- Brand System ثلاثي الطبقات (منصة ← مؤسسة ← مشروع) + منتقي ألوان مخصص.
- اسم ملف التحميل يبدأ باسم المستند ثم المشروع.
- صفحة /demo التجريبية، وتعديل/نسخ المشاريع.
